# What you have been sent, and how to run it

Five files. Two charts, three EAs. Everything below was checked by
`JARVIS/tools/check_pine.py` and `check_mq5.py`; **neither tool can prove a file
compiles** — only TradingView and MetaEditor can say that.

---

## THE CHARTS

Put both on **XAUUSD**. Zone Sniper wants **M1**.

| file | what it draws |
|---|---|
| `JARVIS/pine/ZONE_SNIPER_3_0.pine` | System A — the liquidity/ICT chart |
| `JARVIS/pine/SUPERTREND_CLEAN_4_0.pine` | the SuperTrend chart |

**What is on the candles, complete list.** No background bands, no stacked
labels, no emoji, no level spam:

- the SuperTrend band (coloured by direction on the SuperTrend chart)
- **BUY / SELL** at the fill, small labels
- the **live stop**, as a line that follows the trail
- the **one live level** you are actually waiting for — not every pivot in
  history. It is removed the moment the limit fills or expires.
- an open position shaded between entry and price, blue in profit, red in loss
- a **box on every finished trade** from entry bar to exit bar, entry price to
  exit price, with the points and the money on it
- one **profit box** in the corner

Everything else — ATR, entry price, stop distance, open points, SuperTrend
state — is in the **status line**. Hover the indicator name and it is all there,
off the candles.

Colours, box corner, and every display element are inputs.

### The profit boxes

**Zone Sniper** answers *what is each half of this system worth*, live, on
whatever bars you point it at:

```
── what each part is worth ──
limit in zone        +97.1    shipped
market at signal      +9.5    1159 trades
the level adds       +87.7    points
fill vs signal      +0.705    pts/trade
```

That middle row is a **shadow book**: the same signals, the same stop, the same
trail, buying at the market instead of resting a limit inside the zone. The gap
is what the level is worth. It is free to come out negative — that is the point
of measuring it this way.

For SuperTrend's half, switch **"Only take levels the SuperTrend agrees with"**
off and read the box again. Measured on 981 real trades: **OFF 48.4, ON 97.1**.

**SuperTrend Clean** answers *is the exit machinery paying for itself*:

```
── is the exit paying? ──
SYSTEM              stop / trail / stall
FLIP & HOLD         flip to flip, no exit rules
exit adds           the difference
── how trades ended ──
stop / trail        n / n
stall / time        n / n
```

It also draws a small hollow circle at every flip the **DEMA gate refused**, so
you can see what that filter is costing you. It measured at −3.1 control se —
worse than random — and it still ships ON because that is what the EA does.
Turn it off and compare.

## THE EAs

Each ships twice. **Use the `_SINGLEFILE` version** — one file, drop it in
`MQL5/Experts`, F7, done. The plain version needs `ProfitBox.mqh` in
`MQL5/Include` as well.

| file | magic | what it is |
|---|---|---|
| `ZoneSniper_SINGLEFILE.mq5` | 880041 | **System A.** M1 level + SuperTrend direction + band trail |
| `SuperTrendSniper_SINGLEFILE.mq5` | 770001 | the SuperTrend flip EA |
| `LiquiditySniper_SINGLEFILE.mq5` | 770069 | the level EA, with the funded-account rules |

### The profit box on the EAs

One row per **strategy, keyed by magic number**. Run all three on one account
and every box shows all three books separately:

```
ZONE SNIPER 2.10                    LONG
points              +12.4      +9.76 GBP
today                +3.1      4 trades
trades                 37      9.0/day
win rate            57.1%      21W 16L
avg trade          +0.335      points
── by strategy ──
ZONE  st+liq        +12.4      37 tr  57%W  +9.76
SUPERTREND              -      no trades yet
LIQUIDITY               -      no trades yet
── entry quality ──
fill vs signal     +0.705      pts/trade, 37 limits
── risk ──
best / worst    +8.1 / -4.2    points
max drawdown         -8.4      points
long / short   +7.1 / +5.3     19 / 18
── open ──
unrealised           +0.4      +0.31 GBP
lots                 0.01      spread 0.23
```

Change `InpTrackMagic2` / `InpTrackMagic3` if you use different magics; set one
to 0 to drop its row.

**Points come first and money second** on purpose. E-074: the best per-trade
gate set in this project banked the *least* money.

**Money is the broker's own number** — `DEAL_PROFIT` + swap + commission. It is
never modelled.

**`fill vs signal` is an entry-quality diagnostic, not a share of the profit.**
It is how much better the resting limit filled than the market at the moment the
EA armed. Design offset is 0.50 ATR; the backtest gives +0.705/trade. **If your
live number comes in far below that, your limits are filling late and the edge
is going with them.** That is the row to watch on demo.

## BEFORE YOU RUN ANY OF IT

- **`ZoneSniper` ships with `InpDemoOnly = true` and will refuse to start on a
  live account.** It has never been forward tested.
- **System A breaks even at 0.10 points of exit slippage.** 0.00 → 97.1 pts,
  0.02 → 77.5, 0.05 → 48.1, 0.10 → −1.0. Normal M1 gold stop fills slip
  0.01–0.05, so it survives on roughly half the edge. **Measure your own on
  demo** — that is what the `fill vs signal` row is for.
- Every number quoted here is **2018 H1, one sample, one instrument**. In the
  vocabulary of `EXPERIMENTS.md` this is SUPPORTED, not CONFIRMED. A backtest is
  evidence, never proof.
